Ik vond het een interresante artikel maar ook wel on nodig. Ik vind dat als je dit gebruikt je onnodig veel aan het coderen bent om de elementen te maken. Het laat ook zien hoe erg het web is veranderd en hoe goed we het nu hebben. 

checkbox role
In dit artikel wordt uitgelegd hoe je een checkbox kan maken met ARIA zonder de <input> element te gebruiken. Je geeft een element bijvoorbeeld role="checkbox" zodat screenreaders begrijpen dat het een checkbox is. Met aria-checked geef je aan of de checkbox aan of uit staat. Omdat een div of span niet focusbaar is, moet je ook tabindex="0" toevoegen. Daarnaast moet je met JavaScript zorgen dat de checkbox reageert op klikken en op de spatiebalk, zodat de status kan veranderen. Dat kan met een onclick en een onkeydown.

radio role
Dit artikel legt uit hoe je radio buttons kan maken met ARIA. Net zo als bij de checkbox krijgt een radio button role="radio" en de status wordt aangegeven met aria-checked. Radio buttons moeten altijd in een groep zitten met role="radiogroup". Binnen de groep kan maar één optie tegelijk geselecteerd zijn.

input/checkbox
Dit artikel legt uit hoe de standaard HTML checkbox input werkt: <input type="checkbox">. Hiermee kan een gebruiker een optie aan of uit zetten. Bij de radio button is dat niet mogelijk, je kan alleen één optie selecteren. Dit element heeft al ingebouwde functionaliteit zoals klikken, keyboard support en toegankelijkheid.

input/radio
Het artikel over <input type="radio"> verteld hoe radio buttons in HTML werken. Radio buttons worden gebruikt wanneer een gebruiker slechts één optie uit meerdere opties kan selecteren. Alle radio buttons die bij dezelfde groep horen hebben dezelfde name waarde. Hierdoor zorgt de browser er voor dat wanneer je één optie kiest de andere opties worden gedeselecteerd.

label
Het <label> element wordt gebruikt om een tekstlabel aan een input element te koppelen. Dit maakt het makkelijker voor gebruikers om een formulier te gebruiken, omdat ze ook op de tekst kunnen klikken om de input te activeren. Daarnaast is het belangrijk voor toegankelijkheid, omdat screenreaders hierdoor beter begrijpen bij welke input de tekst hoort.
