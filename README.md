# Sprint 1
## Week 1/ Dag 1

**Wat heb ik vandaag gedaan:**
Vandaag heb ik de kickof bijgewoond. Daar hebben we het over het vak browser tech gehad, en wat we de komende tijd gaan doen. Er werd verteld wat onze eindopdracht is en wat de eisen zijn van de opdracht. Daarna hebben we een korte les gehad van victor waarbij hij de opbouw van een formulier had uitgelegd en voorbeelden liet zien. Na de kickof ben ik bezig geweest met het coderen van mijn formulier. Ik heb de eerste deel van de formulier af kunnen krijgen vandaag maar, hoe meer ik ging typen hoe lastiger ik vond om het te begrijpen omdat ik veel van de zelfde elementen aan het gebruiken was zoals:

`input` `fieldset` `label`

naast deze elementen moest ik ook veel namen maken en gebruik maken van de zelfde attribute.
![figma-ontwerp](./Image/code.png)

**Hoelang duurde het:**
Het duurde mij ongeveer 3 uurtjes om de html van de formulier te coderen.

**Wat heb ik geleerd:**
Ik heb veel niewe code geleerd. Ik heb namelijk nooit zo een uitgebreide formulier gemaakt wat de eerste dag van BT heel leerzaam maakte. Ik heb kennis kunnen maken met, verschillende attribute en wat je ermee kan, `input` `fieldset` `label` `legend`, kleine intro op validatie en de verschillende manieren hoe je een formulier kan structureren.

**Wat ga ik morgen doen:**
Morgen wil ik beginnen met het stylen van mijn formulier aan de hand van de NS huis style en als het kan ook een begin maken aan de tweede pattern van de form.
